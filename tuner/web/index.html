Adds the turbo setup of another installed car to this modded car. Apply copies the donor's turbo files and engine turbo fields into your car; the turbo settings then appear in the Turbo group of the table. A turbo multiplies the engine power on top of its curve, so lower the boost settings if the car becomes too strong. Unverified: whether the game accepts a turbo on a car that has none is not tested yet. In the list, a boost like 0.7 / 0.9 bar is one value per turbo (the max boost of each turbo file); '(reference)' is the engine's own reference value when the turbo files carry none, and no bar means the game data has no boost value for that car.

Tyre Creator

Tyres you create here are saved once and can be ticked in the garage list of any modded car in the Car Tuner tab.

Kunos advises against editing the tyre model values: the code that connects them is not user-controlled, and a changed calibration can make a tyre behave unpredictably (tyres may need too much slip to grip or react nervously). Change little and test in the game.

Session logging

Choose what the logger records. Press Start logger (or double-click start_logger.bat), then start the game: a session file is written to the logs folder while the game runs. Your choices are saved at once and apply from the next session.
